# 21: Patient directory

**What to build:** Staff search Patients by name or phone, create and edit Patients, and view a Patient's contact details, locale, history, visits, and no-show count.

**Blocked by:** 17 — Staff Booking, 19 — Appointment lifecycle

**Status:** ready-for-agent

- [ ] Search supports case-insensitive name contains and exact or partial phone.
- [ ] Staff can create and update Patients without creating a User.
- [ ] Patient detail shows upcoming and past Appointments.
- [ ] Total visits and no-show count are accurate.
- [ ] The list is paginated.
- [ ] Cross-tenant access returns 404 or 403.
