# 16: Team invitations, roles, and clinic switcher

**What to build:** An Owner invites Clinic Admins and Practitioners, manages roles and removals, and users with multiple memberships switch clinics; CASL enforces the role matrix.

**Blocked by:** 05 — Practitioners and Service assignments

**Status:** ready-for-agent

- [ ] Invitations can be sent, resent, cancelled, and accepted by a verified user.
- [ ] Owner, Clinic Admin, and Practitioner permissions match the role matrix.
- [ ] The last Owner cannot be removed or demoted.
- [ ] A Practitioner can edit their own profile, Working Hours, Time Off, and own Appointments, and can read the clinic calendar.
- [ ] Clinic Admins cannot change the Owner, manage billing, or delete the clinic.
- [ ] A user with two memberships can switch clinics and sees only the selected clinic's data.
- [ ] Cross-tenant access to existing resources returns 404 or 403.
- [ ] The clinic UI labels the Practitioner role “Doctor / طبيب” where appropriate.
